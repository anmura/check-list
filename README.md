# Списки

Простое Android-приложение для списков: покупки, дела, что угодно.

- Несколько списков, порядок можно менять.
- В обычном режиме строки только отмечаются, поэтому случайно попасть в редактирование нельзя.
- Редактирование — обычный текст: одна строка = один пункт, пустая строка = отступ между группами.
- «Снять все отметки», чтобы использовать тот же список снова.
- Напоминания для каждого списка: раз в день или каждые 1–4 часа в заданном промежутке, по всем дням, будням или выходным. Уведомление приходит только если в списке остались невыполненные пункты.

Все данные хранятся на телефоне, сервер не нужен.

## Установка

1. Откройте на телефоне страницу [Releases](https://github.com/anmura/check-list/releases) и скачайте последний файл `Spiski-*.apk`.
2. Откройте скачанный файл. Если телефон спросит, разрешите установку приложений из браузера или файлового менеджера.
3. При первом включении напоминаний разрешите уведомления.

Некоторые телефоны (Xiaomi, Huawei, Samsung и др.) агрессивно экономят батарею и могут задерживать напоминания. Если они приходят не вовремя, в настройках приложения «Списки» отключите для него ограничение работы в фоне.

## Как устроено

- `www/` — само приложение: `index.html`, `style.css`, `app.js` (без фреймворков).
- Android-обёртка — [Capacitor](https://capacitorjs.com) 6. Проект `android/` не хранится в репозитории, он создаётся при сборке.
- `android-res/` — иконки приложения и уведомлений.
- `.github/workflows/release.yml` собирает подписанный APK. Сборка запускается при публикации тега `v*` и сама создаёт релиз.

### Новая версия

Actions → Build APK → Run workflow, в поле «Версия» указать, например, `1.0.1`. Сборка создаст тег и релиз с APK. Можно и запушить тег `v1.0.1`.

### Подпись

Чтобы новые версии устанавливались поверх старых без потери данных, APK всегда подписывается одним ключом. Ключ хранится только в секретах репозитория (Settings → Secrets and variables → Actions), в самом репозитории его нет:

- `ANDROID_KEYSTORE_BASE64` — файл ключа (PKCS12) в base64,
- `ANDROID_KEYSTORE_PASSWORD` — пароль от него. Alias ключа: `checklist`.

Создать новый ключ:

```sh
keytool -genkeypair -keystore release.p12 -storetype PKCS12 -alias checklist \
  -keyalg RSA -keysize 2048 -validity 10000
base64 -w0 release.p12   # содержимое для ANDROID_KEYSTORE_BASE64
```

Без этих секретов сборка всё равно пройдёт, но с одноразовым ключом, и следующую версию придётся ставить после удаления старой. Сохраните файл ключа и пароль у себя: если их потерять, обновление поверх старой версии станет невозможно.

### Проверка в браузере

Откройте `www/index.html` в браузере. Всё, кроме уведомлений, работает и там.
