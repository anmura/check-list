Первая версия приложения «Покупки».

- Несколько списков, порядок меняется кнопкой «Порядок».
- Отметка товара нажатием на строку. Редактирование только по кнопке с карандашом, как текст в заметках: одна строка — один товар, пустая строка — отступ.
- «Снять все отметки», чтобы использовать список снова.
- Напоминания для каждого списка: раз в день или каждые 1–4 часа в выбранное время. Приходят, только пока в списке есть невыполненные пункты.

**Как установить:** скачайте файл `.apk` ниже на телефоне, откройте его и разрешите установку из этого источника.
